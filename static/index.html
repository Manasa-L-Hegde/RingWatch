About RingWatch

RingWatch is an autonomous, graph-native fraud ring investigation platform built on FalkorDB. Organized fraud networks actively evade relational database joins by staggering accounts across transitive chains of shared devices, payment cards, and shipping addresses. By leveraging Cypher variable-length path traversal and graph algorithms like Weakly Connected Components (WCC), RingWatch discovers deep entity rings in sub-millisecond graph queries that relational self-joins fail to capture.

The Four Investigation Outcomes

Every investigation deterministically resolves into one of four standard states: PATH_FOUND indicates that a multi-hop connected ring was traversed and verified with graph evidence; ANSWERED_FROM_MEMORY activates when the order shares $\ge 3$ entities with a confirmed historical case in analyst episodic memory, short-circuiting deep tool loops; NOT_LINKED means no shared device or card connections were identified; and UNKNOWN_ENTITY safely aborts if an order or user ID is not registered in the graph database.

Critical Safety Disclaimer

No links found does not mean safe. A clean or isolated graph query indicates only that no shared identifiers currently connect this entity to known rings in the database. It does not preclude synthetic identities, freshly created cards, or external attack vectors not yet recorded in the local graph.
